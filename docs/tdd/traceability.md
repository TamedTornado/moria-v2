## Scope guard

No technical contract authorizes a world generator, physics solver, damage
model, networking layer, player/controller, game rule, heightmap-only world,
full canonical CPU voxel mirror, privileged validation path, unbounded
rollback, Web target, or deterministic presentation claim. Adding any such
capability requires a new approved product requirement before a TECH contract.

`TECH-063` was the removed cross-backend qualification matrix. Its ID is
retired and must not be reused. `TECH-071` is the new canonical fixed-point
math component. REQ-039 remains visible above only to record the later human
amendment; treating its former cross-machine gate as silently implemented
would misrepresent scope.
